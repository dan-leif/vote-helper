# vote-helper-private

**Keep this repository private.** It holds `beliefs.json`, a record of political views.

- Export from Vote Helper (My beliefs → Export or import), save as `beliefs.json` here, commit.
- To restore on another device: copy the file's contents and paste into Vote Helper's Import box.
- `CLAUDE.md` lets you do the walkthrough by chatting with Claude Code in this repo instead of using the page.
